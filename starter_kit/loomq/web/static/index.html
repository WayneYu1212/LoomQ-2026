这张图先告诉我们：两个读数会一起读成 0，或者一起读成 1。它们在这次测量里高度相关。

经过 H 和 CNOT 后，这对量子比特处于 Bell Φ+ 状态。它是一个纠缠态：描述它时，两个量子比特要作为一个整体来写。

|Φ+⟩ = (|00⟩ + |11⟩) / √2

00 / 11 这张图说明一个测量方向里的相关性。想把真实硬件上的完整量子状态看得更完整，还要从更多方向收集信息。

    Origin Wukong 180-2 · 两比特重建

    这个重建状态和目标有多接近？0.952449

    Fidelity：可以先把它读作“重建状态和目标 Bell Φ+ 有多接近”。越接近 1，表示越接近目标。

    技术口径：这是服务商对 Bell Φ+ 纯目标的 overlap / state-fidelity 点估计。

    这个负值怎样帮助我们判断？-0.4561

    PPT λmin：这里得到负值。对这个两比特重建状态，PPT 判据给出“纠缠”的结果。

    什么是密度矩阵？

    密度矩阵是一种记录量子状态统计信息的数学表示。

    为什么负值能说明纠缠？对 2×2 系统，部分转置出现负本征值，意味着这个重建状态满足 PPT 纠缠判据。

    就服务商重建得到的两比特密度矩阵点估计而言，这个状态在 2×2 系统的 PPT 判据下被判定为纠缠态。
